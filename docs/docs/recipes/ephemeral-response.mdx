# Ephemeral slash-command response

Explicitly request a private response for the invoking user. Return the serialized body from the relevant slash-command or interaction handler.

<RecipeOutput recipe="ephemeral-response" outputs={recipeOutputs} />

## Code

<LanguageContent>

<Python>

Reply to a slash command with a message only the invoking user sees:

```python
from slackblocks import MessageResponse, SectionBlock

body = MessageResponse(
    blocks=SectionBlock(":mag: Searching... I'll DM you when I'm done."),
    ephemeral=True,
).json()
print(body)  # return this body from your slash-command handler
```

</Python>

<Go>

```go
package main

import (
	"encoding/json"
	s "github.com/nicklambourne/slackblocks/go/v3"
	"os"
)

func main() {
	value, err := s.NewMessageResponse().Text("Only you can see this").ResponseType("ephemeral").Build()
	if err != nil {
		panic(err)
	}
	if err := json.NewEncoder(os.Stdout).Encode(value); err != nil {
		panic(err)
	}
}
```

<Rust>

Set response visibility explicitly when it matters; return this JSON in your interaction handler.

```rust
use slackblocks::*;
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let response = MessageResponse::builder()
        .response_type(ResponseType::Ephemeral)
        .block(
            SectionBlock::builder()
                .text("Searching... I will DM you when done.")
                .build()?,
        )
        .build()?;
    println!("{}", serde_json::to_string(&response)?);
    Ok(())
}
```

</Rust>
