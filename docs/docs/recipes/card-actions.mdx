# Card actions

A card combines text with up to three buttons. These examples build two cards with
the same approval and rejection actions; the second adds a Details button.

Slackblocks preserves the order supplied to `actions` in the serialized payload.
Slack controls the visual arrangement, so array order is not a positioning API:

| Card | Visual arrangement |
| --- | --- |
| Two buttons | Reject and Approve form a group on the right, with Reject first. |
| Three buttons | Reject sits at the far left; Details and Approve form a group on the right. |

Primary buttons appear furthest right. Adding the third button moves the danger
button across the card. This card-specific rule does not change an ordinary
[Actions block](/usage/recipes/approval-request).

The [official card reference](https://docs.slack.dev/reference/block-kit/blocks/card-block/)
contains this clarification, first observed on 6 November 2026. The two- and three-button arrangements
were also verified in the Slack stress workspace on 7 November 2026, including
all six input orders for one primary, one danger, and one default button.
This is a documentation clarification, with no new field or caller migration.

## Build the cards

The code deliberately supplies Approve before Reject. Expand **Serialized output**
above to compare that array with the preview's visual arrangement. Each button
retains its action ID and request value. Your application still needs to handle
and acknowledge interactions; constructing these messages does not send them.

**Shared example contract:** The same two- and three-button cards in every language. Wire order is deliberate and may differ from Slack’s displayed order.

<LanguageContent>

<Python>

```python
from slackblocks import Button, CardBlock, Message

approve = Button("Approve", action_id="approve", value="release-42", style="primary")
reject = Button("Reject", action_id="reject", value="release-42", style="danger")
details = Button("Details", action_id="details", value="release-42")
message = Message(channel="C1", text="Card actions", blocks=[
    CardBlock(title="Two buttons", body="Review release-42.",
              actions=[approve, reject], block_id="card_two"),
    CardBlock(title="Three buttons", body="Review release-42.",
              actions=[approve, reject, details], block_id="card_three"),
])
print(message.json())
```

```ts
import * as S from "@nicklambourne/slackblocks";

const approve = S.Button().text("Approve").actionId("approve").value("release-42").style("primary");
```

```go
package main

import (
    "encoding/json"
    "os"
    s "github.com/nicklambourne/slackblocks/go/v3"
)

func main() {
    approve := s.NewButton().Text("Approve").ActionID("approve").Value("release-42").Style("primary")
    reject := s.NewButton().Text("Reject").ActionID("reject").Value("release-42").Style("danger")
    details := s.NewButton().Text("Details").ActionID("details").Value("release-42")
    message, err := s.NewMessage().Channel("C1").Text("Card actions").Blocks(
        s.NewCardBlock().Title("Two buttons").Body("Review release-42.").
            Actions(approve, reject).BlockID("card_two"),
        s.NewCardBlock().Title("Three buttons").Body("Review release-42.").
            Actions(approve, reject, details).BlockID("card_three"),
    ).Build()
    if err != nil { panic(err) }
    if err := json.NewEncoder(os.Stdout).Encode(message); err != nil { panic(err) }
}
```

```java
import io.github.nicklambourne.slackblocks.block.CardBlock;
import io.github.nicklambourne.slackblocks.element.ButtonElement;
import io.github.nicklambourne.slackblocks.element.ButtonStyle;
import io.github.nicklambourne.slackblocks.payload.MessagePayload;

public final class Recipe {
  public static void main(String[] args) {
    var approve = ButtonElement.builder().text("Approve").actionId("approve")
        .value("release-42").style(ButtonStyle.PRIMARY).build();
    var reject = ButtonElement.builder().text("Reject").actionId("reject")
        .value("release-42").style(ButtonStyle.DANGER).build();
    var details = ButtonElement.builder().text("Details").actionId("details").value("release-42").build();
```
