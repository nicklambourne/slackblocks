# Multi-column status report

Every language builds a complete message with the same fallback text and a two-column table: Service/Status, API/Healthy, Worker/Degraded. For formatted cells and column alignment, see [Using Blocks](/usage/using_blocks#table-block). These examples print JSON without sending it.

<RecipeOutput recipe="status-table" outputs={recipeOutputs} />

## Code

**Shared example contract:** The same service-status message in every language: Service/Status, API/Healthy and Worker/Degraded.

<LanguageContent>

<Python>

```python
from slackblocks import Message, RawText, TableBlock

rows = [[RawText(text) for text in row] for row in [
    ["Service", "Status"], ["API", "Healthy"], ["Worker", "Degraded"],
]]
report = Message(channel="C1", text="Service status", blocks=[TableBlock(rows=rows)])
print(report.json())
```

</Python>

<TypeScript>

```ts
import * as S from "@nicklambourne/slackblocks";

const table = S.TableBlock()
  .rows([S.RawText().text("Service"), S.RawText().text("Status")])
  .rows([S.RawText().text("API"), S.RawText().text("Healthy")])
  .rows([S.RawText().text("Worker"), S.RawText().text("Degraded")]);
const message = S.Message().channel("C1").text("Service status").blocks(table).build();
console.log(JSON.stringify(message));
```

</TypeScript>

<Go>

```go
package main

import (
	"encoding/json"
	s "github.com/nicklambourne/slackblocks/go/v3"
	"os"
)

func main() {
	value, err := s.NewMessage().Channel("C1").Text("Service status").Blocks(s.NewTableBlock().Rows(
		[]s.TableCell{s.NewRawText().Text("Service"), s.NewRawText().Text("Status")},
		[]s.TableCell{s.NewRawText().Text("API"), s.NewRawText().Text("Healthy")},
		[]s.TableCell{s.NewRawText().Text("Worker"), s.NewRawText().Text("Degraded")},
	)).Build()
	if err != nil {
		panic(err)
	}
	if err := json.NewEncoder(os.Stdout).Encode(value); err != nil {
		panic(err)
	}
}
```

</Go>

```java
import io.github.nicklambourne.slackblocks.*;
import io.github.nicklambourne.slackblocks.block.*;

import io.github.nicklambourne.slackblocks.object.*;
import io.github.nicklambourne.slackblocks.payload.*;
import java.util.List;
import java.util.Map;

public final class Recipe {
  public static void main(String[] args) throws Exception {
    var table = TableBlock.builder().rows(
    List.of(RawText.of("Service"), RawText.of("Status")),
    List.of(RawText.of("API"), RawText.of("Healthy")),
    List.of(RawText.of("Worker"), RawText.of("Degraded"))).build();
    var value = MessagePayload.builder().channel("C1").text("Service status").blocks(table).build();
    System.out.println(value.toJson());
  }
}
```

<Rust>

```rust
use slackblocks::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let table = TableBlock::builder()
        .rows([
            vec![RawText::new("Service")?, RawText::new("Status")?],
            vec![RawText::new("API")?, RawText::new("Healthy")?],
            vec![RawText::new("Worker")?, RawText::new("Degraded")?],
        ])
        .build()?;
    let message = MessagePayload::builder("C1").text("Service status").block(table).build()?;
    println!("{}", serde_json::to_string(&message)?);
    Ok(())
}
```

Plain tables permit ragged rows; data tables require rectangular rows and raw
header cells. `DataTableBlock` also checks its caption and text totals.

```elixir
alias Slackblocks.{Message, Blocks.Table, Objects.RawText}
rows = for row <- [["Service", "Status"], ["API", "Healthy"], ["Worker", "Degraded"]] do
  for text <- row, do: RawText.new!(text: text)
end
Message.new!(channel: "C1", text: "Service status", blocks: [Table.new!(rows: rows)])
|> Slackblocks.to_map!()
```

```haskell
{-# LANGUAGE OverloadedStrings #-}

import Data.Aeson (encode)
import qualified Data.Map.Strict as Map
import Slackblocks

example = do
  rows <-
    traverse
      (traverse (fmap rawTextAsTableCell . buildRawText . rawText))
      [["Service", "Status"], ["API", "Healthy"], ["Worker", "Degraded"]]
  table <- buildTableBlock (tableBlock rows)
  buildMessagePayload ((messagePayload "C1") {messagePayloadText = Just "Service status", messagePayloadBlocks = Just [tableBlockAsBlock table]})
```
