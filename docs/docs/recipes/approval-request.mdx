# Approval request with action buttons

Every language builds the same message: a deployment question, Approve/Reject actions carrying `release-42`, and a Details link. The application authenticates and acknowledges callbacks through HTTP or Socket Mode and implements the approve/reject actions. No request is sent by these examples.

<RecipeOutput recipe="approval-request" outputs={recipeOutputs} />

## Code

**Shared example contract:** The same release-42 approval message in every language: Approve, Reject and Details, with matching actions and fallback text.

<LanguageContent>

<Python>

```python
from slackblocks import ActionsBlock, Button, Message, SectionBlock

message = Message(channel="C1", text="Approval requested", blocks=[
    SectionBlock("Approve deployment?"),
    ActionsBlock(elements=[
        Button(text="Approve", action_id="approve", value="release-42", style="primary"),
        Button(text="Reject", action_id="reject", value="release-42", style="danger"),
        Button(text="Details", action_id="details", url="https://approvals.example.com/release-42"),
    ]),
])
print(message.json())
```

<Rust>

Your interaction handler matches the action ID and reads the request ID from the button value.

```rust
use slackblocks::*;
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let actions = ActionsBlock::builder()
        .element(
            ButtonElement::builder()
                .text("Approve")
                .action_id("approve")
                .value("release-42")
                .style(ButtonStyle::Primary)
                .build()?,
        )
        .element(
            ButtonElement::builder()
                .text("Reject")
                .action_id("reject")
                .value("release-42")
                .style(ButtonStyle::Danger)
                .build()?,
        )
        .element(ButtonElement::builder().text("Details").action_id("details").url("https://approvals.example.com/release-42").build()?)
        .build()?;
    let message = MessagePayload::builder("C1")
        .text("Approval requested")
        .block(
            SectionBlock::builder()
                .text("Approve deployment?")
                .build()?,
        )
        .block(actions)
        .build()?;
    println!("{}", serde_json::to_string(&message)?);
    Ok(())
}
```

```haskell
{-# LANGUAGE OverloadedStrings #-}

import Data.Aeson (encode)
import qualified Data.Map.Strict as Map
import Slackblocks

example = do
  question <- buildMarkdownText (markdownText "Approve deployment?")
  section <- buildSectionBlock (sectionBlock {sectionBlockText = Just (markdownTextAsText question)})
  yes <- buildPlainText (plainText "Approve")
  no <- buildPlainText (plainText "Reject")
  approve <- buildButtonElement ((buttonElement yes) {buttonElementActionId = Just "approve", buttonElementValue = Just "release-42", buttonElementStyle = Just ButtonStylePrimary})
  reject <- buildButtonElement ((buttonElement no) {buttonElementActionId = Just "reject", buttonElementValue = Just "release-42", buttonElementStyle = Just ButtonStyleDanger})
  label <- buildPlainText (plainText "Details")
  details <- buildButtonElement ((buttonElement label) {buttonElementActionId = Just "details", buttonElementUrl = Just "https://approvals.example.com/release-42"})
  actions <- buildActionsBlock (actionsBlock [buttonElementAsElement approve, buttonElementAsElement reject, buttonElementAsElement details])
  buildMessagePayload ((messagePayload "C1") {messagePayloadText = Just "Approval requested", messagePayloadBlocks = Just [sectionBlockAsBlock section, actionsBlockAsBlock actions]})
```
