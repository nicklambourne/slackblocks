# Elements

This page documents the Ruby API for elements. Values use keyword-only construction, validate before freezing, and serialize to Slack JSON.

## ButtonElement

An interactive button that sends a payload or opens a URL.

See the [Slack reference](https://docs.slack.dev/reference/block-kit/block-elements/button-element).

### .new

Construct an immutable, validated value with keyword arguments. Required keywords: text.

```ruby
def self.new: (text: String | PlainText, ?action_id: (String)?, ?url: (String)?, ?value: (String)?, ?style: (:primary | :danger)?, ?confirm: (Confirmation)?, ?accessibility_label: (String)?, ?additional_fields: Hash[String | Symbol, untyped]?) -> ButtonElement
```

| Parameter | Description |
| --- | --- |
| `text` | Sets the button label. |
| `action_id` | Sets the identifier Slack returns in interaction payloads when a user acts on this element. It must be unique among the elements of its block. |
| `url` | Sets a URL opened in the user's browser when the button is clicked. Slack still sends an interaction payload. |
| `value` | Sets the application-defined value sent in interaction payloads. |
| `style` | Sets the button's emphasis. Omit it for the default neutral style. |
| `confirm` | Sets a confirmation dialog shown before the action is sent. |
| `accessibility_label` | Sets the label read by screen readers in place of the visible text. |
| `additional_fields` | JSON-compatible extension fields that do not replace modeled wire keys. |

**Returns:** ButtonElement

| Throws | When |
| --- | --- |
| [`ValidationError`](/reference/ruby/errors#validationerror) | A field or cross-field Slack rule fails. |

**Related types:** [`ButtonElement`](/reference/ruby/elements#buttonelement), [`Confirmation`](/reference/ruby/objects#confirmation), [`PlainText`](/reference/ruby/objects#plaintext)

## ButtonStyle

Visual emphasis for buttons and confirmation dialogs. Pass the wire symbol to constructor keywords.

| Constant | Slack value | Meaning |
| --- | --- | --- |
| `PRIMARY` | `:primary` | Green emphasis for the affirmative action. |
| `DANGER` | `:danger` | Red emphasis for destructive actions. |
