# Blocks

This page documents the Ruby API for blocks. Values use keyword-only construction, validate before freezing, and serialize to Slack JSON.

## ActionsBlock

A block that holds interactive elements such as buttons and menus.

See the [Slack reference](https://docs.slack.dev/reference/block-kit/blocks/actions-block).

### .new

Construct an immutable, validated value with keyword arguments. Required keywords: elements.

```ruby
def self.new: (elements: Array[Element], ?block_id: (String)?, ?additional_fields: Hash[String | Symbol, untyped]?) -> ActionsBlock
```

| Parameter | Description |
| --- | --- |
| `elements` | Adds interactive elements in display order. |
| `block_id` | Sets a unique identifier for this block. Slack returns it in interaction payloads, so use a stable value when you need to find the block again. |
| `additional_fields` | JSON-compatible extension fields that do not replace modeled wire keys. |

**Returns:** ActionsBlock

| Throws | When |
| --- | --- |
| [`ValidationError`](/reference/ruby/errors#validationerror) | A field or cross-field Slack rule fails. |

**Related types:** [`ActionsBlock`](/reference/ruby/blocks#actionsblock), [`Element`](/reference/ruby/elements#element)

### elements

Adds interactive elements in display order. Wire key: elements.

```ruby
def elements: () -> Array[Element]
```

**Returns:** Array[Element]

**Related types:** [`Element`](/reference/ruby/elements#element)

### block_id

Sets a unique identifier for this block. Slack returns it in interaction payloads, so use a stable value when you need to find the block again. Wire key: block_id.

```ruby
def block_id: () -> (String)?
```

**Returns:** (String)?

### with

Return a newly validated value with changed keywords.

```ruby
def with: (**untyped changes) -> ActionsBlock
```

**Returns:** ActionsBlock

**Related types:** [`ActionsBlock`](/reference/ruby/blocks#actionsblock)

### to_h

Return structural Ruby members, including additional_fields. Nested members remain frozen.

```ruby
def to_h: () -> Hash[Symbol, untyped]
```

### as_json

Return a fresh, detached Slack wire Hash.

```ruby
def as_json: (?untyped options) -> Hash[String, untyped]
```

### to_json

Encode the Slack wire payload as JSON.

```ruby
def to_json: (?untyped options) -> String
```

| --- | --- |
| `hero_image` | Sets the image displayed prominently at the top of the card. |
| `icon` | Sets the image displayed beside the title. |

| `subtitle` | Sets the supporting text shown below the title. |
| `body` | Sets the main body text of the card. |

## ContainerBlock

A titled group of blocks that can optionally collapse.

See the [Slack reference](https://docs.slack.dev/reference/block-kit/blocks/container-block).

### .new

Construct an immutable, validated value with keyword arguments. Required keywords: child_blocks.

```ruby
def self.new: (child_blocks: Array[Block], ?title: (String | PlainText)?, ?rich_text_title: (RichTextBlock)?, ?subtitle: (String | Text)?, ?width: (:narrow | :standard | :wide | :full)?, ?icon: (ImageElement)?, ?is_collapsible: (bool)?, ?default_collapsed: (bool)?, ?has_header_divider: (bool)?, ?block_id: (String)?, ?additional_fields: Hash[String | Symbol, untyped]?) -> ContainerBlock
```

| Parameter | Description |
| --- | --- |
| `child_blocks` | Adds the blocks grouped inside the container, in display order. |
| `title` | Sets the container title. Provide either a title or a rich text title. |
| `rich_text_title` | Sets a rich text block used as the title in place of a plain-text title. |
| `subtitle` | Sets the supporting text shown below the title. |
| `width` | Sets the horizontal width of the container. |
| `icon` | Sets the image displayed beside the title. |
| `is_collapsible` | Sets whether users can collapse and expand the container. |
| `default_collapsed` | Sets whether a collapsible container starts collapsed. Requires the container to be collapsible. |
| `has_header_divider` | Sets whether Slack draws a divider below the container header. Only valid for non-collapsible containers. |
| `block_id` | Sets a unique identifier for this block. Slack returns it in interaction payloads, so use a stable value when you need to find the block again. |
| `additional_fields` | JSON-compatible extension fields that do not replace modeled wire keys. |

**Returns:** ContainerBlock

| Throws | When |
| --- | --- |
| [`ValidationError`](/reference/ruby/errors#validationerror) | A field or cross-field Slack rule fails. |

**Related types:** [`Block`](/reference/ruby/blocks#block), [`ContainerBlock`](/reference/ruby/blocks#containerblock), [`ImageElement`](/reference/ruby/elements#imageelement), [`PlainText`](/reference/ruby/objects#plaintext), [`RichTextBlock`](/reference/ruby/blocks#richtextblock), [`Text`](/reference/ruby/objects#text)
