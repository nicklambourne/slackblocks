# JSON and public types

Signatures come from GHC; descriptions come from compiled Haddock comments. Import `Slackblocks` or the defining public module. Checked values encode with Aeson; field records must be built first.

## FromSlackJSON {#slackblocks-json-fromslackjson}

Validate an Aeson value as a supported modeled type. It is not an arbitrary Slack event parser.

```haskell
type Slackblocks.Json.FromSlackJSON :: * -> Constraint
```

## decimalText {#slackblocks-json-decimaltext}

Exact numeric convenience for a number-input bound. No binary floating-point
 conversion is performed; the wire representation remains a decimal string.

```haskell
Slackblocks.Json.decimalText ::
  Data.Scientific.Scientific -> Data.Text.Text
```

## decode {#slackblocks-json-decode}

Decode UTF-8 JSON bytes, rejecting duplicate keys, trailing input, numeric
 exponent overflow in Aeson's Scientific representation and invalid modeled values.

```haskell
Slackblocks.Json.decode ::
  Slackblocks.Json.FromSlackJSON a =>
  Data.ByteString.Lazy.ByteString -> Slackblocks.Validation.Result a
```

## fromSlackJSON {#slackblocks-json-fromslackjson}

Check nested fields and receiving context; return structured validation errors.

```haskell
Slackblocks.Json.fromSlackJSON ::
  Slackblocks.Json.FromSlackJSON a =>
  Data.Aeson.Value -> Slackblocks.Validation.Result a
```

## fromValue {#slackblocks-json-fromvalue}

Validate an already parsed value. Use decode to retain duplicate-key and UTF-8 checks on raw bytes.

```haskell
Slackblocks.Json.fromValue ::
  Slackblocks.Json.FromSlackJSON a =>
  Data.Aeson.Value -> Slackblocks.Validation.Result a
```
