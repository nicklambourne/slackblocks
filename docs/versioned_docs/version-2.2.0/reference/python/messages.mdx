# Messages

## Message

**Class**

```python
Message(channel: 'str', text: 'str | None' = '', blocks: 'list[Block] | Block | None' = None, attachments: 'list[Attachment] | None' = None, thread_ts: 'str | None' = None, mrkdwn: 'bool' = True, unfurl_links: 'bool | None' = None, unfurl_media: 'bool | None' = None) -> 'None'
```

<div className="api-docstring">

A Slack message object that can be converted to a JSON string for use with
the Slack message API.

<h3>Arguments</h3>

| Argument | Type | Description |
| --- | --- | --- |
| `channel` | <code>str</code> | the Slack channel to send the message to, e.g. "#general". |
| `text` | <code>str &#124; None</code> | markdown text to send in the message. If `blocks` are provided<br />then this is a fallback to display in notifications. |
| `blocks` | <code>list[<a href="/reference/python/blocks#block">Block</a>] &#124; <a href="/reference/python/blocks#block">Block</a> &#124; None</code> | a list of [`Blocks`](/reference/python/blocks) to form the contents<br />of the message instead of the contents of `text`. |
| `attachments` | <code>list[<a href="/reference/python/attachments#attachment">Attachment</a>] &#124; None</code> | a list of<br />[`Attachments`](/reference/python/attachments#attachment)<br />that form the secondary contents of the message (deprecated). |
| `thread_ts` | <code>str &#124; None</code> | the timestamp ID of another unthreaded message that will<br />become the parent message of this message (now a reply in a thread). |
| `mrkdwn` | <code>bool</code> | if `True` the contents of `text` will be rendered as markdown<br />rather than plain text. |
| `unfurl_links` | <code>bool &#124; None</code> | if `True`, links in the message will be automatically<br />unfurled. |
| `unfurl_media` | <code>bool &#124; None</code> | if `True`, media from links (e.g. images) will<br />automatically unfurl. |

Raises:
    InvalidUsageException: in the event that the items passed to `blocks`
        are not valid [`Blocks`](/reference/python/blocks).

</div>

## WebhookMessage

**Class**

```python
WebhookMessage(text: 'str | None' = None, attachments: 'Attachment | list[Attachment] | None' = None, blocks: 'Block | list[Block] | None' = None, response_type: 'ResponseType | str | None' = None, replace_original: 'bool | None' = None, delete_original: 'bool | None' = None, unfurl_links: 'bool | None' = None, unfurl_media: 'bool | None' = None, metadata: 'dict[str, Any] | None' = None, headers: 'dict[str, str] | None' = None) -> 'None'
```

<div className="api-docstring">

Messages sent via the Slack `WebhookClient` takes different arguments than
    those sent via the regular `WebClient`.

See: [https://github.com/slackapi/python-slack-sdk/blob/7e71b73/slack_sdk/webhook/client.py#L28](https://github.com/slackapi/python-slack-sdk/blob/7e71b73/slack_sdk/webhook/client.py#L28)

<h3>Arguments</h3>

| Argument | Type | Description |
| --- | --- | --- |
| `text` | <code>str &#124; None</code> | markdown text to send in the message. If `blocks` are provided<br />then this is a fallback to display in notifications. |
| `attachments` | <code><a href="/reference/python/attachments#attachment">Attachment</a> &#124; list[<a href="/reference/python/attachments#attachment">Attachment</a>] &#124; None</code> | a list of<br />[`Attachments`](/reference/python/attachments#attachment)<br />that form the secondary contents of the message (deprecated). |
| `blocks` | <code><a href="/reference/python/blocks#block">Block</a> &#124; list[<a href="/reference/python/blocks#block">Block</a>] &#124; None</code> | a list of [`Blocks`](/reference/python/blocks) to form the contents<br />of the message instead of the contents of `text`. |
| `response_type` | <code><a href="/reference/python/messages#responsetype">ResponseType</a> &#124; str &#124; None</code> | one of `ResponseType.EPHEMERAL` or `ResponseType.IN_CHANNEL`.<br />Ephemeral messages are shown only to the requesting user whereas<br />"in-channel" messages are shown to all channel participants. |
| `replace_original` | <code>bool &#124; None</code> | when `True`, the message triggering this response will be<br />replaced by this message. Mutually exclusive with `delete_original`. |
| `delete_original` | <code>bool &#124; None</code> | when `True`, the original message triggering this response<br />will be deleted, and any content of this message will be posted as a<br />new message. Mutually exclusive with `replace_original`. |
| `unfurl_links` | <code>bool &#124; None</code> | if `True`, links in the message will be automatically<br />unfurled. |
| `unfurl_media` | <code>bool &#124; None</code> | if `True`, media from links (e.g. images) will<br />automatically unfurl. |
| `metadata` | <code>dict[str, Any] &#124; None</code> | additional metadata to attach to the message. |
| `headers` | <code>dict[str, str] &#124; None</code> | HTTP request headers to include with the message. |

<h3>Errors</h3>

| Error | When |
| --- | --- |
| <code><a href="/reference/python/errors#invalidusageerror">InvalidUsageError</a></code> | when any of the passed fields fail validation. |

</div>
