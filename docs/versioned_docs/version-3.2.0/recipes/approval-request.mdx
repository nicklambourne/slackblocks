# Approval request with action buttons

Carry a stable request identifier in action values. The application must authenticate callbacks and implement the approve/reject actions.

<RecipeOutput recipe="approval-request" outputs={recipeOutputs} />

## Code

<LanguageContent>

<Python>

An approval flow with approve, reject and details buttons. The buttons carry `value` or `action_id` so your interaction handler can identify them.

```python
from slackblocks import (
    ActionsBlock,
    Button,
    ContextBlock,
    HeaderBlock,
    Message,
    SectionBlock,
    Text,
)


def approval_request(*, channel: str, request_id: str, requester: str, summary: str) -> Message:
    return Message(
        channel=channel,
        text=f"Approval requested by {requester}",
        blocks=[
            HeaderBlock(":hand: Approval needed"),
            SectionBlock(text=f"*Requested by:* {requester}\n\n{summary}"),
            ActionsBlock(
                block_id=f"approval:{request_id}",
                elements=[
                    Button(
                        text="Approve",
                        action_id="approve",
                        value=request_id,
                        style="primary",
                    ),
                    Button(
                        text="Reject",
                        action_id="reject",
                        value=request_id,
                        style="danger",
                    ),
                    Button(
                        text="View details",
                        action_id="details",
                        url=f"https://approvals.example.com/{request_id}",
                    ),
                ],
            ),
            ContextBlock(
                elements=[Text(f"Request ID: `{request_id}`")],
            ),
        ],
    )
print(approval_request(channel="C1", request_id="release-42", requester="Nick", summary="Deploy version 3.1.0?").json())
```

When the user clicks a button, Slack will POST an interaction payload to your app. Match on `action_id` (`approve` / `reject` / `details`) and pull the request ID from `block_id` or the button's `value`.

<Rust>

Your interaction handler matches the action ID and reads the request ID from the button value.

```rust
use slackblocks::*;
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let actions = ActionsBlock::builder()
        .element(
            ButtonElement::builder()
                .text("Approve")
                .action_id("approve")
                .value("release-42")
                .style(ButtonStyle::Primary)
                .build()?,
        )
        .element(
            ButtonElement::builder()
                .text("Reject")
                .action_id("reject")
                .value("release-42")
                .style(ButtonStyle::Danger)
                .build()?,
        )
        .build()?;
    let message = MessagePayload::builder("C01234567")
        .text("Approval requested")
        .block(
            SectionBlock::builder()
                .text("Approve this release?")
                .build()?,
        )
        .block(actions)
        .build()?;
    println!("{}", serde_json::to_string(&message)?);
    Ok(())
}
```

{-# LANGUAGE OverloadedStrings #-}

import Data.Aeson (encode)
import qualified Data.Map.Strict as Map
import Slackblocks

example = do
  question <- buildMarkdownText (markdownText "*Approve deployment?*")
  section <- buildSectionBlock (sectionBlock {sectionBlockText = Just (markdownTextAsText question)})
  yes <- buildPlainText (plainText "Approve")
  no <- buildPlainText (plainText "Reject")
  approve <- buildButtonElement ((buttonElement yes) {buttonElementActionId = Just "approve", buttonElementValue = Just "482", buttonElementStyle = Just ButtonStylePrimary})
  reject <- buildButtonElement ((buttonElement no) {buttonElementActionId = Just "reject", buttonElementValue = Just "482", buttonElementStyle = Just ButtonStyleDanger})
  actions <- buildActionsBlock (actionsBlock [buttonElementAsElement approve, buttonElementAsElement reject])
  buildMessagePayload ((messagePayload "C1") {messagePayloadText = Just "Approval requested", messagePayloadBlocks = Just [sectionBlockAsBlock section, actionsBlockAsBlock actions]})
