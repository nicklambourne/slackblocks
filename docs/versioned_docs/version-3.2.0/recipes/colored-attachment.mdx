# Colored-bar attachment

Use a legacy attachment when an existing integration needs a colored side bar. Prefer regular blocks for new layouts.

<RecipeOutput recipe="colored-attachment" outputs={recipeOutputs} />

## Code

<LanguageContent>

<Python>

Slack has long deprecated message attachments, but they're still the only way to get the colored vertical bar on the left of a message. `slackblocks` supports them when you really need that styling:

```python
from slackblocks import (
    Attachment,
    Color,
    Message,
    SectionBlock,
)

msg = Message(
    channel="#alerts",
    text="Disk usage warning",
    attachments=[
        Attachment(
            color=Color.YELLOW,
            blocks=[SectionBlock(":warning: `/var` is at 87% capacity on `prod-db-1`.")],
        ),
    ],
)
print(msg.json())
```

Prefer plain blocks where possible — Slack may drop attachment support in the future.

</Python>

<Go>

```go
package main

import (
	"encoding/json"
	s "github.com/nicklambourne/slackblocks/go/v3"
	"os"
)

func main() {
	value, err := s.NewMessage().Channel("C1").Text("Checks passed").Attachments(
		s.NewAttachment().Color("good").Blocks(s.NewSectionBlock().Text("All checks passed")),
	).Build()
	if err != nil {
		panic(err)
	}
	if err := json.NewEncoder(os.Stdout).Encode(value); err != nil {
		panic(err)
	}
}
```

<Rust>

Attachments are a legacy Slack feature. `AttachmentColor` supports semantic colors, named constants and checked six-digit hex parsing.

```rust
use slackblocks::*;
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let attachment = Attachment::builder()
        .color(AttachmentColor::YELLOW)
        .block(
            SectionBlock::builder()
                .text(":warning: Disk usage is at 87%.")
                .build()?,
        )
        .build()?;
    let message = MessagePayload::builder("C01234567")
        .text("Disk usage warning")
        .attachment(attachment)
        .build()?;
    println!("{}", serde_json::to_string(&message)?);
    Ok(())
}
```
