# Preview in Block Kit Builder

Generate a Block Kit Builder URL locally. The preview below decodes that exact URL; generating it does not send a Slack message.

<RecipeOutput recipe="builder-preview" outputs={recipeOutputs} />

## Code

<LanguageContent>

<Python>

Use `block_kit_builder_url` to build a [Block Kit Builder](https://app.slack.com/block-kit-builder) URL and open it in your browser to verify a message before posting it. Useful while iterating on layout — no Slack credentials needed.

```python
from slackblocks import (
    block_kit_builder_url,
    DividerBlock,
    HeaderBlock,
    Markdown,
    SectionBlock,
)

blocks = [
    HeaderBlock("Build #482 passed :white_check_mark:", block_id="build"),
    SectionBlock(text=Markdown("All 1,247 tests green in 3m 12s."), block_id="summary"),
    DividerBlock(block_id="divider"),
    SectionBlock(fields=["*Author*\n@nick", "*Branch*\n`main`"], block_id="details"),
]

print(block_kit_builder_url(blocks))
# https://app.slack.com/block-kit-builder/#%7B%22blocks%22%3A%5B...%5D%7D
```

`block_kit_builder_url` accepts:

- A single `Block`, `Element`, or anything else with a `_resolve()` method.
- A list of `Block` objects (wrapped in `{"blocks": [...]}` automatically).
- A `Message`, `WebhookMessage`, `MessageResponse`, or `View`.
- A raw `dict` (escape hatch).

Pass `team_id="T0123ABCD"` for a workspace-specific URL.

</Python>

<Go>

Go has no dedicated Builder URL helper. Encode a validated payload as the URL fragment using the standard library; this makes no network request.

```go
package main

import (
	"encoding/json"
	"fmt"
	s "github.com/nicklambourne/slackblocks/go/v3"
	"net/url"
)

func main() {
	value, err := s.NewMessage().Channel("C1").Text("Preview").Blocks(s.NewSectionBlock().Text("Preview *this*")).Build()
	if err != nil {
		panic(err)
	}
	wire, err := json.Marshal(value)
	if err != nil {
		panic(err)
	}
	link := url.URL{Scheme: "https", Host: "app.slack.com", Path: "/block-kit-builder/", Fragment: string(wire)}
	fmt.Println(link.String())
}
```

</Go>

<Java>

```java
import io.github.nicklambourne.slackblocks.*;
import io.github.nicklambourne.slackblocks.block.*;
import io.github.nicklambourne.slackblocks.component.*;
import io.github.nicklambourne.slackblocks.element.*;
import io.github.nicklambourne.slackblocks.object.*;
import io.github.nicklambourne.slackblocks.payload.*;
import java.util.List;
import java.util.Map;

public final class Recipe {
  public static void main(String[] args) throws Exception {
    var value = MessagePayload.builder().channel("C1").text("Preview").blocks(
    SectionBlock.builder().markdownText("Preview *this*").build()).build();
    String fragment = java.net.URLEncoder.encode(value.toJson(), java.nio.charset.StandardCharsets.UTF_8).replace("+", "%20");
    System.out.println("https://app.slack.com/block-kit-builder/#" + fragment);
  }
}
```

<Rust>

The helper encodes UTF-8 JSON in a Builder URL without sending a request. It borrows blocks and payloads.

```rust
use slackblocks::*;
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let block: Block = SectionBlock::builder()
        .text("Preview this message")
        .build()?
        .into();
    println!("{}", block_kit_builder_url(&block, Some("T0123ABCD"))?);
    Ok(())
}
```
