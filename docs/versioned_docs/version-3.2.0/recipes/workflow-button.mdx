# Workflow button

Build a workflow trigger with named input parameters. Replace the example URL with your real link trigger; this example does not activate a workflow.

<RecipeOutput recipe="workflow-button" outputs={recipeOutputs} />

## Code

<LanguageContent>

<Python>

`Workflow.from_url` collapses the most common workflow construction:

```python
from slackblocks import (
    ActionsBlock,
    Message,
    SectionBlock,
    Workflow,
    WorkflowButton,
)

msg = Message(
    channel="#release",
    blocks=[
        SectionBlock("Run the release workflow with the parameters below."),
        ActionsBlock(
            elements=[
                WorkflowButton(
                    text="Release",
                    action_id="release",
                    workflow=Workflow.from_url(
                        "https://slack.com/shortcuts/Ft012KXZK1MZ/...",
                        env="prod",
                        retries="3",
                    ),
                ),
            ],
        ),
    ],
)
print(msg.json())
```

Each keyword pair becomes one `InputParameter` on the underlying `Trigger`. Calling `Workflow.from_url(url)` with no parameters omits the `customizable_input_parameters` field.

</Python>

<TypeScript>

```ts
import * as S from "@nicklambourne/slackblocks";

const workflow = S.Workflow().trigger(S.Trigger().url("https://slack.com/shortcuts/Ft123/example")
  .customizableInputParameters(S.InputParameter().name("env").value("prod")));
const button = S.WorkflowButton().text("Release").actionId("release").workflow(workflow).build();
console.log(JSON.stringify(button));
```

<Go>

```go
package main

import (
	"encoding/json"
	s "github.com/nicklambourne/slackblocks/go/v3"
	"os"
)

func main() {
	value, err := s.NewWorkflowButton().Text("Release").ActionID("release").Workflow(
		s.NewWorkflow().Trigger(s.NewTrigger().URL("https://slack.com/shortcuts/Ft123/example").CustomizableInputParameters(
			s.NewInputParameter().Name("env").Value("prod"),
		)),
	).Build()
	if err != nil {
		panic(err)
	}
	if err := json.NewEncoder(os.Stdout).Encode(value); err != nil {
		panic(err)
	}
}
```

import io.github.nicklambourne.slackblocks.block.*;

public final class Recipe {

    var workflow = Workflow.builder().trigger(Trigger.builder().url("https://slack.com/shortcuts/Ft123/example")
    .customizableInputParameters(InputParameter.builder().name("env").value("prod").build()).build()).build();
    var value = WorkflowButtonElement.builder().text("Release").actionId("release").workflow(workflow).build();

  }

<Rust>

Input parameters retain iterator order. An empty iterator omits the parameter list.

```rust
use slackblocks::*;
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let workflow = Workflow::from_url(
        "https://slack.com/shortcuts/Ft012KXZK1MZ/example",
        [
            InputParameter::builder()
                .name("env")
                .value("prod")
                .build()?,
            InputParameter::builder()
                .name("retries")
                .value("3")
                .build()?,
        ],
    )?;
    let button = WorkflowButtonElement::builder()
        .text("Release")
        .action_id("release")
        .workflow(workflow)
        .build()?;
    println!("{}", serde_json::to_string(&button)?);
    Ok(())
}
```

See [Troubleshooting](/usage/troubleshooting) for typed error handling, omission rules and safe editing.
