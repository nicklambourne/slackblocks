# Multi-column status report

Present a compact service report using native table cells. The code and preview use the same selected-language output.

<RecipeOutput recipe="status-table" outputs={recipeOutputs} />

## Code

<LanguageContent>

<Python>

`TableBlock` is useful for compact tabular output.

```python
from slackblocks import (
    ColumnSettings,
    Message,
    RawText,
    RichText,
    RichTextSection,
    TableBlock,
)


def header_cell(text: str) -> RichTextSection:
    return RichTextSection(elements=[RichText(text=text, bold=True)])


report = Message(
    channel="#ops",
    text="Daily service report",
    blocks=[
        TableBlock(
            column_settings=[
                ColumnSettings(align="left"),
                ColumnSettings(align="right"),
                ColumnSettings(align="right"),
            ],
            rows=[
                [header_cell("Service"), header_cell("p99 (ms)"), header_cell("Errors")],
                [RawText("api"),     RawText("142"), RawText("3")],
                [RawText("worker"),  RawText("89"),  RawText("0")],
                [RawText("billing"), RawText("310"), RawText("12")],
            ],
        ),
    ],
)
print(report.json())
```

```ts
const table = S.TableBlock()

```

<Go>

```go
package main

import (
	"encoding/json"
	s "github.com/nicklambourne/slackblocks/go/v3"
	"os"
)

func main() {
	value, err := s.NewTableBlock().Rows(
		[]s.TableCell{s.NewRawText().Text("Service"), s.NewRawText().Text("Status")},
		[]s.TableCell{s.NewRawText().Text("API"), s.NewRawText().Text("Healthy")},
	).Build()
	if err != nil {
		panic(err)
	}
	if err := json.NewEncoder(os.Stdout).Encode(value); err != nil {
		panic(err)
	}
}
```

</Go>

```java
import java.util.Map;

public final class Recipe {

    List.of(RawText.of("API"), RawText.of("Healthy"))).build();
    System.out.println(value.toJson());
  }
}
```

```rust
use slackblocks::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let table = TableBlock::builder()
        .rows([
            vec![RawText::new("Service")?, RawText::new("Status")?],
            vec![RawText::new("API")?, RawText::new("Healthy")?],
        ])
        .build()?;
    println!("{}", serde_json::to_string(&table)?);
    Ok(())
}
```

Plain tables permit ragged rows; data tables require rectangular rows and raw
header cells. `DataTableBlock` also checks its caption and text totals.

<Elixir>

```elixir
alias Slackblocks.{Message, Blocks.Table, Objects.RawText}
rows = for row <- [["Service", "Status"], ["API", "Healthy"], ["Worker", "Degraded"]] do
  for text <- row, do: RawText.new!(text: text)
end
Message.new!(channel: "C1", text: "Service status", blocks: [Table.new!(rows: rows)])
|> Slackblocks.to_map!()
```
