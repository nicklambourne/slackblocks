# Accordion and pagination

Combine collapsible detail with a page of content and navigation. Your application owns the page state and rebuilds the payload when a navigation callback arrives.

<RecipeOutput recipe="accordion-pagination" outputs={recipeOutputs} />

## Code

<LanguageContent>

<Python>

Python has no named Accordion/Paginator helper. Compose native blocks and keep paging state in the application. Your callback handler reads the destination page and rebuilds the message.

```python
from slackblocks import ActionsBlock, Button, ContainerBlock, Message, SectionBlock

items = ["Result one", "Result two"]
page, page_size = 1, 1
visible = items[(page - 1) * page_size:page * page_size]
blocks = [ContainerBlock(title="Details", is_collapsible=True, child_blocks=[SectionBlock("Ready")])]
blocks.extend(SectionBlock(item) for item in visible)
if page * page_size < len(items):
    blocks.append(ActionsBlock(elements=[Button(text="Next", action_id="items.next", value=str(page + 1))]))
print(Message(channel="C1", text="Items", blocks=blocks).json())
```

</Python>

```ts
import * as S from "@nicklambourne/slackblocks";

const message = S.Message().channel("C1").text("Items").blocks(
  S.Accordion().sections(S.AccordionSection().title("Details").blocks(S.SectionBlock().text("Ready"))),
  S.Paginator().actionIdPrefix("items").page(1).pageSize(1).blocks(S.SectionBlock().text("One"), S.SectionBlock().text("Two")),
).build();
console.log(JSON.stringify(message));
```

```java
import io.github.nicklambourne.slackblocks.*;
import io.github.nicklambourne.slackblocks.block.*;
import io.github.nicklambourne.slackblocks.component.*;
import io.github.nicklambourne.slackblocks.element.*;
import io.github.nicklambourne.slackblocks.object.*;
import io.github.nicklambourne.slackblocks.payload.*;
import java.util.List;
import java.util.Map;

public final class Recipe {
  public static void main(String[] args) throws Exception {
    var details = Accordion.builder().sections(AccordionSection.builder("Details")
    .blocks(SectionBlock.builder().markdownText("Ready").build()).build()).build();
    var page = Paginator.builder("items").page(1).pageSize(1).blocks(
    SectionBlock.builder().markdownText("One").build(), SectionBlock.builder().markdownText("Two").build()).build();
    var value = MessagePayload.builder().channel("C1").text("Items").blocks(details.toArray(Block[]::new)).blocks(page.toArray(Block[]::new)).build();
    System.out.println(value.toJson());
  }
}
```

<Rust>

```rust
use slackblocks::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let details = AccordionSection::builder("Details")
        .block(SectionBlock::builder().text("All checks passed").build()?)
        .build()?;
    let accordion = Accordion::new([details])?;
    let page = Paginator::builder("builds", [
            SectionBlock::builder().text("One").build()?,
            SectionBlock::builder().text("Two").build()?,
        ])
        .page_size(1)
        .build()?;
    let message = MessagePayload::builder("C01234567")
        .text("Build details")
        .blocks(accordion.into_iter().chain(page))
        .build()?;
    println!("{}", serde_json::to_string(&message)?);
    Ok(())
}
```

Pagination uses one-based pages. Navigation action IDs end in `.previous` or
`.next`, and button values contain the destination page. Your interaction handler
rebuilds the next page. The receiving message validates limits after expansion.

</Rust>

<Haskell>

```haskell
{-# LANGUAGE OverloadedStrings #-}

import Data.Aeson (encode)
import qualified Data.Map.Strict as Map
import Slackblocks

example :: Result MessagePayload
example = do
  title <- buildPlainText (plainText "Details")
  text <- buildMarkdownText (markdownText "Ready")
  section <- buildSectionBlock (sectionBlock {sectionBlockText = Just (markdownTextAsText text)})
  container <- buildContainerBlock (accordionSection title [sectionBlockAsBlock section])
  expanded <- accordion [container]
  page <-
    paginate
      ((paginator "items") {paginatorPageSize = 1})
      [sectionBlockAsBlock section, sectionBlockAsBlock section]
  buildMessagePayload
    ( (messagePayload "C1")
        { messagePayloadText = Just "Items",
          messagePayloadBlocks = Just (expanded <> page)
        }
    )
```
