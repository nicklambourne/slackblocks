# Components and Utilities

Generated from the actual Rust signatures and rustdoc comments. Builders validate on `build()`; `into_builder()` preserves omissions. Error categories and paths are stable; prose may improve.

## Accordion

A nonempty ordered collection of collapsible sections.

Rendering produces ordinary blocks; the receiving message/view builder checks
its own surface and total block-count constraints after expansion.

### new

Collects validated sections in display order.

**Errors**
Returns `missing-required` when no section is supplied.

```rust
fn new(
    sections: impl IntoIterator<Item = AccordionSection>,
) -> Result<Self, ValidationError>
```

**Related types:** [`AccordionSection`](/reference/rust/components#accordionsection), [`ValidationError`](/reference/rust/errors#validationerror)

### sections

Borrows the ordered sections.

```rust
fn sections(&self) -> &[AccordionSection]
```

**Related types:** [`AccordionSection`](/reference/rust/components#accordionsection)

### render

Renders owned blocks while retaining this accordion for reuse.

```rust

```

**Related types:** [`Block`](/reference/rust/core#block)

## block_kit_builder_url

Creates a Slack Block Kit Builder URL without performing any network requests.
Optional team IDs are encoded as a single path segment. JSON is encoded as UTF-8.

**Errors**
Returns a Serde error if the supplied payload cannot be serialized.

### block_kit_builder_url

```rust
fn block_kit_builder_url<'a>(
    payload: impl Into<BuilderPayload<'a>>,
    team_id: Option<&str>,
) -> Result<String, serde_json::Error>
```

**Related types:** [`BuilderPayload`](/reference/rust/components#builderpayload), [`block_kit_builder_url`](/reference/rust/components#block_kit_builder_url)

## BuilderPayload

Borrowed input shapes for a Block Kit Builder preview URL.

Blocks are wrapped in a `blocks` object. Payloads are serialized as-is. `Raw`
is an explicit, unvalidated escape hatch for an existing JSON object.

| Constant | Wire value or payload type | Meaning |
| --- | --- | --- |
| `Block` | `(& 'a Block)` | One validated block. |
| `Blocks` | `(& 'a [Block])` | Ordered validated blocks. |
| `Message` | `(& 'a MessagePayload)` | A chat message payload. |
| `Webhook` | `(& 'a WebhookMessage)` | An incoming webhook payload. |
| `Response` | `(& 'a MessageResponse)` | An interaction response payload. |
| `Modal` | `(& 'a ModalView)` | A modal view. |
| `Home` | `(& 'a HomeTabView)` | A Home tab view. |
| `Raw` | `(& 'a Map < String , Value >)` | A JSON object constructed outside the validated API. |

## Paginator

A validated page of blocks and its navigation controls.

Rendered blocks are ordinary values. Receiving message/view builders validate
surface and aggregate constraints after pagination has expanded the controls.

### builder

Starts at page one with five content blocks per page.

```rust
fn builder<I, T>(action_id_prefix: impl Into<String>, blocks: I) -> PaginatorBuilder
where
    I: IntoIterator<Item = T>,
    T: Into<Block>,
```

**Related types:** [`Block`](/reference/rust/core#block), [`PaginatorBuilder`](/reference/rust/components#paginatorbuilder)
