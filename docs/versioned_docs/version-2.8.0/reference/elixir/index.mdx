# Elixir API reference

Elixir 1.16.3+ with compatible OTP 26.2+ on 64-bit systems. The first release is being prepared for 2.8.0; see [installation](/usage/installation). These pages cover all public value structs, tagged and raising constructors/changes, typespecs and helpers.

- [Blocks](/reference/elixir/blocks)
- [Elements](/reference/elixir/elements)
- [Composition Objects and Rich Text](/reference/elixir/objects)
- [Messages, Attachments and Views](/reference/elixir/payloads)
- [Components and Utilities](/reference/elixir/components)
- [JSON, Validation and Types](/reference/elixir/core)
- [Validation Errors](/reference/elixir/errors)

The same modules are callable from Erlang; see [Erlang integration](/usage/erlang). Jason encoding revalidates values. Checked decoding preserves number tokens and rejects duplicate keys; existing Jason build caches may need the documented rebuild step.
