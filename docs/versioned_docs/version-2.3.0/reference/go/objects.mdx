# Composition Objects

This page documents the public Go API for composition objects. Every constructor and method shown here is part of the fluent `github.com/nicklambourne/slackblocks/go/v2` package.

## NewAreaChart

NewAreaChart creates an area-chart object.

```go
func NewAreaChart() *AreaChartBuilder
```

### AreaChartBuilder

AreaChartBuilder is the concrete fluent builder returned by NewAreaChart.

An area chart for a data visualization block.

- Required: Series and AxisConfig.
- Every series needs exactly one data point for each axis category.

See the [Slack reference](https://docs.slack.dev/reference/block-kit/blocks/data-visualization-block).

Use NewAreaChart rather than constructing this type directly.

```go
type AreaChartBuilder struct { /* contains filtered or unexported fields */ }
```

Its fluent methods return the same concrete builder, so invalid fields are rejected at compile time. Parameters use the interfaces and enums on [Interfaces And Enums](/reference/go/types), so values of the wrong kind are rejected at compile time too.

#### AreaChartBuilder.Series

Series adds data series in display order. Series names must be unique. Required. Must contain
between 1 and 12 items. Each call appends to any values already added.

```go
func (b *AreaChartBuilder) Series(values ...*DataSeriesBuilder) *AreaChartBuilder
```

#### AreaChartBuilder.AxisConfig

AxisConfig sets the axis categories and labels. Every series needs exactly one point per
category. Required.

```go
func (b *AreaChartBuilder) AxisConfig(value *AxisConfigBuilder) *AreaChartBuilder
```

Every `AreaChartBuilder` also provides `Build() (Object, error)`, `MustBuild() Object`, and JSON marshaling. `Set(field, value)` is available as an advanced raw wire-format escape hatch; it deliberately ends the typed fluent chain.
