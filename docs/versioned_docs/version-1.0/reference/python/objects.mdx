```

<div className="api-docstring">{"Convenience wrapper for `Text` with `type_=TextType.MARKDOWN`.\n\n`Markdown(\"_italic_\", verbatim=True)` is equivalent to\n`Text(\"_italic_\", type_=TextType.MARKDOWN, verbatim=True)`.
