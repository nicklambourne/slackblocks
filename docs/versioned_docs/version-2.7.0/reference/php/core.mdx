## JsonObject

Immutable, opaque application JSON. An empty instance encodes as &#123;&#125;, not []. Nested objects are copied on input and export; modeled validation never traverses this content.

### __construct

Copies opaque object members into immutable JSON storage.

```php
public function __construct(stdClass|array $fields = [])
```

| Parameter | Description |
| --- | --- |
| `fields` | array&lt;string\|int, mixed&gt;\|\stdClass — Object members, including explicit nulls. |

| Throws | When |
| --- | --- |
| [`ValidationError`](/reference/php/errors#validationerror) | Members contain invalid UTF-8, nonfinite numbers, cycles or unsupported values. |

### fromJson

Parses object-shaped JSON, rejecting unsupported numeric ranges and malformed UTF-8.

```php
public static function fromJson(string $json): self
```

| Parameter | Description |
| --- | --- |
| `json` | string — Complete JSON object text, including quoted member names. |

**Returns:** self A detached opaque object; empty objects remain objects.

| Throws | When |
| --- | --- |
| [`ValidationError`](/reference/php/errors#validationerror) | JSON syntax, root type, numeric range or member data is invalid. |

### jsonSerialize

Returns a detached object, preserving nested &#123;&#125; versus [] and explicit nulls.

```php
public function jsonSerialize(): stdClass
```

### toArray

Exports a detached copy of the opaque object members.

```php
public function toArray(): array
```

**Returns:** array&lt;string\|int, mixed&gt; Detached members; nested objects remain stdClass.

### toJson

Encodes without exposing the internal storage.

```php
public function toJson(): string
```


| --- | --- |
