# Composition Objects

This page documents the Ruby API for composition objects. Values use keyword-only construction, validate before freezing, and serialize to Slack JSON.

## AreaChart

An area chart for a data visualization block.

See the [Slack reference](https://docs.slack.dev/reference/block-kit/blocks/data-visualization-block).

### .new

Construct an immutable, validated value with keyword arguments. Required keywords: series, axis_config.

```ruby
def self.new: (series: Array[DataSeries], axis_config: AxisConfig, ?additional_fields: Hash[String | Symbol, untyped]?) -> AreaChart
```

| Parameter | Description |
| --- | --- |
| `series` | Adds data series in display order. Series names must be unique. |
| `axis_config` | Sets the axis categories and labels. Every series needs exactly one point per category. |
| `additional_fields` | JSON-compatible extension fields that do not replace modeled wire keys. |

**Returns:** AreaChart

| Throws | When |
| --- | --- |
| [`ValidationError`](/reference/ruby/errors#validationerror) | A field or cross-field Slack rule fails. |

**Related types:** [`AreaChart`](/reference/ruby/objects#areachart), [`AxisConfig`](/reference/ruby/objects#axisconfig), [`DataSeries`](/reference/ruby/objects#dataseries)

### .[]

Keyword-only alias for .new.

```ruby
def self.[]: (series: Array[DataSeries], axis_config: AxisConfig, ?additional_fields: Hash[String | Symbol, untyped]?) -> AreaChart
```

**Returns:** AreaChart

**Related types:** [`AreaChart`](/reference/ruby/objects#areachart), [`AxisConfig`](/reference/ruby/objects#axisconfig), [`DataSeries`](/reference/ruby/objects#dataseries)

### series

Adds data series in display order. Series names must be unique. Wire key: series.

```ruby
def series: () -> Array[DataSeries]
```

**Returns:** Array[DataSeries]

**Related types:** [`DataSeries`](/reference/ruby/objects#dataseries)

### axis_config

Sets the axis categories and labels. Every series needs exactly one point per category. Wire key: axis_config.

```ruby
def axis_config: () -> AxisConfig
```

**Returns:** AxisConfig

**Related types:** [`AxisConfig`](/reference/ruby/objects#axisconfig)

### additional_fields

Return frozen extension fields with normalized string keys.

```ruby
def additional_fields: () -> Hash[String, untyped]
```

### with

Return a newly validated value with changed keywords.

```ruby
def with: (**untyped changes) -> AreaChart
```

**Returns:** AreaChart

**Related types:** [`AreaChart`](/reference/ruby/objects#areachart)

### to_h

Return structural Ruby members, including additional_fields. Nested members remain frozen.

```ruby

```
