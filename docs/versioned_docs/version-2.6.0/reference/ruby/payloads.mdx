# Payloads And Views

This page documents the Ruby API for payloads and views. Values use keyword-only construction, validate before freezing, and serialize to Slack JSON.

## Attachment

A legacy message attachment containing blocks and an optional color bar.

See the [Slack reference](https://docs.slack.dev/messaging/formatting-message-text#when-to-use-attachments).

### .new

Construct an immutable, validated value with keyword arguments. Required keywords: blocks.

```ruby
def self.new: (blocks: Array[Block], ?color: (String)?, ?fallback: (String)?, ?additional_fields: Hash[String | Symbol, untyped]?) -> Attachment
```

| Parameter | Description |
| --- | --- |
| `blocks` | Adds the attachment's blocks in display order. |
| `color` | Sets the attachment's left border color: a six-digit hex color or good, warning, or danger. |
| `fallback` | Sets plain-text summary shown in clients that cannot display attachments. |
| `additional_fields` | JSON-compatible extension fields that do not replace modeled wire keys. |

**Returns:** Attachment

| Throws | When |
| --- | --- |
| [`ValidationError`](/reference/ruby/errors#validationerror) | A field or cross-field Slack rule fails. |

**Related types:** [`Attachment`](/reference/ruby/payloads#attachment), [`Block`](/reference/ruby/blocks#block)

### .[]

Keyword-only alias for .new.

```ruby
def self.[]: (blocks: Array[Block], ?color: (String)?, ?fallback: (String)?, ?additional_fields: Hash[String | Symbol, untyped]?) -> Attachment
```

**Returns:** Attachment

**Related types:** [`Attachment`](/reference/ruby/payloads#attachment), [`Block`](/reference/ruby/blocks#block)

### blocks

Adds the attachment's blocks in display order. Wire key: blocks.

```ruby

```

**Returns:** Array[Block]

**Related types:** [`Block`](/reference/ruby/blocks#block)

```ruby

```

**Returns:** (String)?

### fallback


**Returns:** (String)?

## MessagePayload

A complete payload for chat.postMessage and related Web API methods.

See the [Slack reference](https://docs.slack.dev/reference/methods/chat.postMessage).

### .new

Construct an immutable, validated value with keyword arguments. Required keywords: channel.

```ruby
def self.new: (channel: String, ?blocks: (Array[Block])?, ?attachments: (Array[Attachment])?, ?text: (String)?, ?mrkdwn: (bool)?, ?unfurl_links: (bool)?, ?unfurl_media: (bool)?, ?metadata: (Hash[String | Symbol, untyped])?, ?additional_fields: Hash[String | Symbol, untyped]?) -> MessagePayload
```

| Parameter | Description |
| --- | --- |
| `channel` | Sets the ID of the channel, private group, or conversation that receives the message. |
| `blocks` | Adds the message blocks in display order. |
| `attachments` | Adds legacy attachments in display order. |
| `text` | Sets the fallback text used in notifications and by clients that cannot display blocks. |
| `mrkdwn` | Sets whether Slack formats the top-level text as mrkdwn. |
| `unfurl_links` | Sets whether Slack unfurls text-based links. |
| `unfurl_media` | Sets whether Slack unfurls media links. |
| `metadata` | Sets message metadata as a JSON-compatible map, such as event_type and event_payload. |
| `additional_fields` | JSON-compatible extension fields that do not replace modeled wire keys. |

| --- | --- |

## ModalView

The view payload for views.open, views.push, and views.update.

See the [Slack reference](https://docs.slack.dev/surfaces/modals).

### .new

Construct an immutable, validated value with keyword arguments. Required keywords: title, blocks.

```ruby
def self.new: (title: String | PlainText, blocks: Array[Block], ?close: (String | PlainText)?, ?submit: (String | PlainText)?, ?private_metadata: (String)?, ?callback_id: (String)?, ?clear_on_close: (bool)?, ?notify_on_close: (bool)?, ?external_id: (String)?, ?submit_disabled: (bool)?, ?additional_fields: Hash[String | Symbol, untyped]?) -> ModalView
```

| Parameter | Description |
| --- | --- |
| `title` | Sets the title in the modal's top bar. |
| `blocks` | Adds the blocks shown in the modal, in display order. |
| `close` | Sets the label of the button that closes the modal. |
| `submit` | Sets the label of the button that submits the modal. |
| `private_metadata` | Sets application-defined data returned in view payloads. |
| `callback_id` | Sets an identifier returned in view payloads so your app can recognize the view. |
| `clear_on_close` | Sets whether closing this modal closes every view in its stack. |
| `notify_on_close` | Sets whether Slack sends a view_closed event when the user closes the modal. |
| `external_id` | Sets a workspace-unique identifier you can use to update the view later. |
| `submit_disabled` | Sets whether the submit button starts disabled. Only valid in workflow configuration modals. |
| `additional_fields` | JSON-compatible extension fields that do not replace modeled wire keys. |

**Returns:** ModalView

| Throws | When |
| --- | --- |
| [`ValidationError`](/reference/ruby/errors#validationerror) | A field or cross-field Slack rule fails. |

**Related types:** [`Block`](/reference/ruby/blocks#block), [`ModalView`](/reference/ruby/payloads#modalview), [`PlainText`](/reference/ruby/objects#plaintext)

## ResponseType

Visibility of a slash-command or interaction response. Pass the wire symbol to constructor keywords.

| Constant | Slack value | Meaning |
| --- | --- | --- |
| `IN_CHANNEL` | `:in_channel` | Visible to everyone in the channel. |
| `EPHEMERAL` | `:ephemeral` | Visible only to the user who triggered the response. |
