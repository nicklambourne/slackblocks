## AlertBlock

**Class**

```python
AlertBlock(text: 'TextLike', level: 'AlertLevel' = 'default', block_id: 'str | None' = None) -> 'None'
```

<div className="api-docstring">

A severity-labelled alert displayed in a modal.

See: [https://docs.slack.dev/reference/block-kit/blocks/alert-block](https://docs.slack.dev/reference/block-kit/blocks/alert-block).

<h3>Arguments</h3>

| Argument | Type | Description |
| --- | --- | --- |
| `text` | `TextLike` | the text to display in the alert (max 200 chars). Can be a<br />string or `Text` object. |
| `level` | `AlertLevel` | the severity of the alert, one of `default`, `info`,<br />`warning`, `error`, or `success`. |
| `block_id` | `str \| None` | you can use this field to provide a deterministic identifier for the block. |

<h3>Errors</h3>

| Error | When |
| --- | --- |
| `InvalidUsageError` | if any of the provided arguments fail validation. |

</div>

### from_dict

```python
from_dict(data: 'dict[str, Any]') -> 'AlertBlock'
```

<div className="api-docstring">

Parse a Slack block payload back into the appropriate ``Block`` subclass.

Reads ``data["type"]`` and dispatches to the matching subclass's
``from_dict``.

Block types that currently round-trip: ``AlertBlock``,
``ContextBlock`` (text elements only), ``DividerBlock``,
``FileBlock``, ``HeaderBlock``, ``ImageBlock``, ``MarkdownBlock``,
``SectionBlock`` (without an accessory), and ``VideoBlock``.

<h3>Errors</h3>

| Error | When |
| --- | --- |
| `MissingRequiredError` | if ``data["type"]`` is absent. |
| `TypeMismatchError` | if ``data["type"]`` is not a recognised<br />block type. |
| `NotImplementedError` | when the block type is recognised but its<br />round-trip parser depends on a part of the API that is not<br />yet implemented (currently: ``RichTextBlock`` and any block<br />containing nested elements, cards, tasks, charts, or<br />rich text -- ``ActionsBlock``, ``InputBlock``,<br />``TableBlock``, ``CardBlock``, ``CarouselBlock``,<br />``ContainerBlock``, ``ContextActionsBlock``,<br />``DataTableBlock``, ``DataVisualizationBlock``,<br />``TaskCardBlock``, and ``PlanBlock`` -- see Phase 7.4b<br />and 7.4c). |

</div>

## CardBlock

**Class**

```python
CardBlock(hero_image: 'Image | None' = None, icon: 'Image | None' = None, title: 'TextLike | None' = None, subtitle: 'TextLike | None' = None, body: 'TextLike | None' = None, actions: 'Button | list[Button] | None' = None, slack_icon: 'SlackIcon | None' = None, subtext: 'TextLike | None' = None, block_id: 'str | None' = None) -> 'None'
```

<div className="api-docstring">

A compact card with text, images, and up to three actions. Cards can
stand alone or be grouped in a
[`CarouselBlock`](/reference/python/blocks#carouselblock).

At least one of `hero_image`, `title`, `actions`, or `body` must be
provided.

See: [https://docs.slack.dev/reference/block-kit/blocks/card-block](https://docs.slack.dev/reference/block-kit/blocks/card-block).

<h3>Arguments</h3>

| Argument | Type | Description |
| --- | --- | --- |
| `hero_image` | `Image \| None` | an `Image` element displayed prominently at the top<br />of the card. |
| `icon` | `Image \| None` | an `Image` element displayed as the card's icon. Cannot be<br />combined with `slack_icon`. |
| `title` | `TextLike \| None` | the card's title (max 150 chars). Can be a string or `Text` object. |
| `subtitle` | `TextLike \| None` | the card's subtitle (max 150 chars). Can be a string or `Text` object. |
| `body` | `TextLike \| None` | the card's body text (max 200 chars). Can be a string or `Text` object. |
| `actions` | `Button \| list[Button] \| None` | up to three `Button` elements presented as card actions. |
| `slack_icon` | `SlackIcon \| None` | a `SlackIcon` naming a Slack-provided icon. Cannot be<br />combined with `icon`. |
| `subtext` | `TextLike \| None` | additional text displayed at the bottom of the card<br />(max 200 chars). Can be a string or `Text` object. |
| `block_id` | `str \| None` | you can use this field to provide a deterministic identifier for the block. |

<h3>Errors</h3>

| Error | When |
| --- | --- |
| `InvalidUsageError` | if any of the provided arguments fail validation,<br />or both `icon` and `slack_icon` are provided. |

</div>

## ContainerBlock

**Class**

```python
ContainerBlock(child_blocks: 'list[Block]', title: 'TextLike | None' = None, rich_text_title: 'RichTextBlock | None' = None, subtitle: 'TextLike | None' = None, width: 'ContainerWidth' = 'standard', icon: 'Image | None' = None, is_collapsible: 'bool' = False, default_collapsed: 'bool' = False, has_header_divider: 'bool' = False, block_id: 'str | None' = None) -> 'None'
```

<div className="api-docstring">

A titled container grouping up to ten supported child blocks.

One of `title` or `rich_text_title` must be provided.

See: [https://docs.slack.dev/reference/block-kit/blocks/container-block](https://docs.slack.dev/reference/block-kit/blocks/container-block).

<h3>Arguments</h3>

| Argument | Type | Description |
| --- | --- | --- |
| `child_blocks` | `list[Block]` | a list of between 1 and 10 blocks to display inside<br />the container. Supported child block types are actions, context,<br />divider, file, header, image, input, rich text, section, table,<br />and video blocks. |
| `title` | `TextLike \| None` | the container's title (plaintext only; max 150 chars). |
| `rich_text_title` | `RichTextBlock \| None` | a `RichTextBlock` used as the container's title in<br />place of `title`. |
| `subtitle` | `TextLike \| None` | the container's subtitle (max 150 chars). Can be a string<br />or `Text` object. |
| `width` | `ContainerWidth` | the width of the container, one of `narrow`, `standard`,<br />`wide`, or `full`. |
| `icon` | `Image \| None` | an `Image` element displayed alongside the title. |
| `is_collapsible` | `bool` | whether the container can be collapsed by the user. |
| `default_collapsed` | `bool` | whether the container is initially collapsed<br />(requires `is_collapsible=True`). |
| `has_header_divider` | `bool` | whether a divider is shown under the header<br />(only valid on non-collapsible containers). |
| `block_id` | `str \| None` | you can use this field to provide a deterministic identifier for the block. |

<h3>Errors</h3>

| Error | When |
| --- | --- |
| `InvalidUsageError` | if any of the provided arguments fail validation,<br />or an unsupported child block type is provided. |

</div>
