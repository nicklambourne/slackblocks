# Elements

This page documents the public Java API for elements, generated from the Javadoc by the javadoc tool. Values are immutable, builders are concrete and fluent, validation runs when you call `.build()`, and typed getters read built values back.

## ButtonElement

An interactive button that sends a payload or opens a URL.

Start with [`builder()`](/reference/java/elements#buttonelement), set fields with the named fluent methods, and call [`Builder.build()`](/reference/java/elements#buttonelement) to validate and create an immutable value.

- Required: `text`, `actionId`.

See the [Slack reference](https://docs.slack.dev/reference/block-kit/block-elements/button-element).

Starts a new builder.

```java
public static ButtonElement.Builder builder()
```

**Returns:** a new builder

**Related types:** [`ButtonElement`](/reference/java/elements#buttonelement)

Start with [`builder()`](/reference/java/elements#staticmultiselectelement), set fields with the named fluent methods, and call [`Builder.build()`](/reference/java/elements#staticmultiselectelement) to validate and create an immutable value.

- Required: `actionId`.

- Use options or option groups, not both.

See the [Slack reference](https://docs.slack.dev/reference/block-kit/block-elements/multi-select-menu-element).

### Builder

Starts a new builder.

```java
public static StaticMultiSelectElement.Builder builder()
```

**Returns:** a new builder

**Related types:** [`StaticMultiSelectElement`](/reference/java/elements#staticmultiselectelement)
